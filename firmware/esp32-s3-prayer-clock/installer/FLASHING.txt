ADHAN CLOCK - MANUAL FIRMWARE INSTALLATION

Supported hardware
------------------
LCDWIKI ES3N28P with ESP32-S3, 16 MB flash, 8 MB PSRAM, 240x320 ILI9341
display, and ES8311 audio codec. Do not install this image on another board.

The browser installer is the recommended method:
https://drhammadkhan.github.io/Adhancron/

Manual installation with esptool
--------------------------------
1. Install Python 3.
2. Install esptool:

   python -m pip install esptool

3. Connect the board with a USB data cable.
4. Find its serial port.
5. Erase and flash the merged image at offset 0:

   python -m esptool --chip esp32s3 --port YOUR_SERIAL_PORT erase_flash
   python -m esptool --chip esp32s3 --port YOUR_SERIAL_PORT --baud 460800 write_flash 0x0 adhan-clock-esp32-s3.bin

Optional: install the bundled adhan and Eid takbeer recordings into the
internal audio partition:

   python -m esptool --chip esp32s3 --port YOUR_SERIAL_PORT --baud 460800 write_flash 0x310000 storage.bin

This replaces the internal adhan and takbeer recordings with the bundled
defaults. It does not erase Wi-Fi, location, or other settings unless you also
run erase_flash.

Experimental voice-command firmware
-----------------------------------
The experimental voice build has a different partition table because it also
needs an ESP-SR speech model partition. Use the browser installer where
possible. For manual flashing, write the merged image at offset 0:

   python -m esptool --chip esp32s3 --port YOUR_SERIAL_PORT erase_flash
   python -m esptool --chip esp32s3 --port YOUR_SERIAL_PORT --baud 460800 write_flash 0x0 adhan-clock-esp32-s3-voice.bin

The merged voice image includes the bootloader, voice partition table,
application, and ESP-SR model partition. The browser installer also writes a
voice-storage.bin recordings image at the voice firmware's audio partition
offset. If you are flashing manually and want the bundled recordings
immediately, write:

   python -m esptool --chip esp32s3 --port YOUR_SERIAL_PORT --baud 460800 write_flash 0x510000 voice-storage.bin

The voice firmware is USB-first while the microphone command path is being
tested. Use the standard firmware for normal OTA updates.

On macOS, a port normally looks like /dev/cu.usbmodemXXXX.
On Windows, it normally looks like COM3 or another COM number.

If the board is not detected, hold BOOT, tap RESET, release RESET, then release
BOOT and retry. Close any serial monitor before flashing.

First boot
----------
1. Wait for the display to show the setup instructions.
2. Join the Wi-Fi network "Adhancron Setup" using password "adhancron".
3. Open http://192.168.4.1 and save the home Wi-Fi credentials.
4. Reconnect to the home Wi-Fi and open the IP address shown on the clock.
5. Save the location, playback output, volume, and enabled prayers.

Future firmware updates
-----------------------
This release adds safe Wi-Fi updates. After this one USB installation, the
clock checks the published Adhan Clock release automatically and installs new
application versions outside prayer and audio-playback windows. The dashboard
shows the installed version and also provides a manual update check.

The manual erase_flash command removes saved settings and uploaded audio.
If the internal adhan recording is missing after setup, the clock downloads the
published default adhan MP3 automatically when Wi-Fi is available. The browser
installer's "Install default recordings" option and the manual storage.bin flash
install both bundled audio files immediately over USB. A FAT32 microSD card
containing /adhan.mp3 or /takbeer.mp3 can still be used for one-time import.
Both recordings can be replaced independently from the device dashboard.
